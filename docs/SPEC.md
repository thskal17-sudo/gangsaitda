# 강사잇다 기획서

작성 중인 문서입니다. **확정된 것만** 적고, 아직 정하지 않은 것은 `미정`으로 남겨둡니다.
`CLAUDE.md`와 이 문서가 어긋날 때는 **이 문서가 기준**입니다.

---

## 1. 메뉴 구조 (강사 화면)

하단 탭 **2개**로 시작합니다.

| 탭 | 주소 | 이 탭에서 하는 일 | 현재 상태 |
|---|---|---|---|
| 홈 | `/` | 미정 | 빈 화면 |
| 공고 | `/jobs` | 지원할 수 있는 공고 목록 보기 | 목록 완성 (샘플 데이터) |

### 정해진 것

- 탭은 화면 **아래에 고정**되어 있고, 어느 화면에서든 항상 보입니다.
- 지금 보고 있는 탭은 **연보라 알약 배경 + 진한 보라 아이콘 + 굵은 글씨**로 표시하고,
  나머지는 배경 없이 회색으로 둡니다. 색 하나에만 기대지 않아 구분이 쉽습니다.
- 화면 위쪽에는 서비스 이름(`강사잇다`)만 있는 얇은 띠가 있습니다.

### 아직 정하지 않은 것

- 홈 화면에 무엇을 보여줄지
- 공고 필터·검색
- 공고를 눌렀을 때 나오는 상세 화면
- 로그인 화면을 어디에 붙일지 (탭 안 / 탭 밖)
- 탭을 더 늘릴지 (예: 지원현황, 스크랩, MY)

> 탭 개수는 **2개로 시작**합니다. (`CLAUDE.md`도 이 문서를 따르도록 고쳐두었습니다.)
> 탭을 늘리기로 하면 `components/bottom-nav.tsx` 맨 위의 `TABS` 목록에 한 줄씩 추가하면 됩니다.

## 2. 공고 화면 (`/jobs`)

### 다루는 수업

방과후·평생교육·기업강의 등 **여러 종류를 함께** 다룹니다.
그래서 카드에는 어느 수업이든 공통으로 있는 정보만 넣습니다.

### 공고 카드에 보이는 것

| 위치 | 내용 | 예시 |
|---|---|---|
| 위 왼쪽 | 기관명 | 새솔초등학교 |
| 위 오른쪽 | 남은 날짜 배지 | `D-9` |
| 가운데 | 공고 제목 (길면 두 줄까지) | 방과후 코딩(스크래치) 강사 모집 |
| 아래 | 지역 · 마감일 | 서울 마포구 · 9월 25일(금) 마감 |

강사료·수업 시간은 카드에 넣지 않습니다. 공고를 눌렀을 때(상세 화면, 아직 안 만듦) 보여줍니다.

### 남은 날짜 배지

| 남은 날 | 표시 | 색 |
|---|---|---|
| 당일 | 오늘 마감 | 주황 배경 |
| 1~3일 | 마감임박 D-2 | 주황 배경 |
| 4일 이상 | D-9 | 회색 테두리 |

'3일'은 `components/job-card.tsx`의 `URGENT_DAYS` 한 곳에서 바꿀 수 있습니다.

### 목록 규칙

- **마감이 가까운 순**으로 보여줍니다.
- 마감이 지난 공고는 목록에 **보이지 않습니다**.
- 날짜는 서버가 어디에 있든 **한국 시간 기준**으로 계산합니다.
- 화면 맨 위에 "지원할 수 있는 공고 N건"으로 개수를 보여줍니다. 0건이면 안내 문구가 나옵니다.

### 지금 상태

- 데이터베이스가 아직 없어서 **샘플 공고 5개**를 씁니다. 화면에도 "샘플입니다"라고 적어두었습니다.
- Supabase를 붙이면 `lib/jobs.ts`의 `getOpenJobs` 안쪽만 바꾸면 됩니다. 화면 코드는 그대로 둡니다.
- 카드는 아직 눌러도 아무 일도 일어나지 않습니다. 상세 화면을 만들 때 연결합니다.

## 3. 화면 크기 기준

- 강사 화면: **390px** 기준으로 설계. 넓은 화면에서는 가운데 430px 폭으로 모아 보여줍니다.
- 기관 콘솔(데스크톱)은 지금 만들지 않습니다.
